# Проверки сборки 3.0.0

На 20.10.2026 локально пройдены 53 автоматические проверки: 19 проверок качества данных прежнего исправления и 34 проверки нового контура. Использованы настоящие установленные библиотеки приложения; сетевые ответы заменены тестовыми. В ограниченном Windows-окружении использована отдельная оболочка цикла событий без сетевых сокетов. В обычном окружении команда: `python -m unittest discover -v`.

## Что проверено

| Группа | Контроль |
|---|---|
| Миграция | Сохранение прежних настроек, резервная копия, integrity_check и восстановление |
| Полнота | Настоящий ноль при полном покрытии; Н/Д при неполном; ошибка одного кабинета не исчезает из общего результата |
| Спрос | Нулевая база, редкий/новый товар, рост и падение с взаимной компенсацией, сверка валового и чистого изменения |
| Ключи | Кабинеты не смешиваются, варианты не дублируют карточку, подтверждённая комплектность учитывается |
| Источники | Постраничные заказы до пустой страницы, дробная точность курсора, повтор/частичная загрузка, отсутствие персональных полей |
| Остатки | Широкий CSV по датам, пустое не равно нулю, часовой пояс среза, нет выдуманной непрерывной недоступности |
| Гипотезы | Цена не доказывает причину; сценарии не складываются; без экономики нет вывода о прибыли |
| Реклама | Расход нижнего уровня не размножается; неподтверждённая атрибуция не вычитается из общих заказов |
| Отчёты | Неизменяемые ревизии, повтор фактов не создаёт новую, неоднозначная доставка не повторяется, журнал действий |
| Безопасность | Белый список, запрет бизнес-изменяющих API, защита Excel/CSV от формул в строковых данных |
| Выгрузка | Сохранённые числа и проценты, текстовые ID, график с пропусками, полный ZIP при превышении лимита |

Демонстрационный Excel построен на пяти вымышленных карточках двух кабинетов за 90 дней (450 дневных строк). Шесть пользовательских листов просмотрены после независимого импорта и визуализации. Данные помечены как синтетические. Импорт/просмотр Excel не является проверкой рабочего WB API или десктопного Microsoft Excel.

## Что необходимо для завершения реальной приёмки

1. Копия существующей data/bot.db и окружение/панель Bothost через согласованный доступ; секреты не отправлять в чат.
2. Миграция на копии именно рабочей базы, подтверждение сохранения пользователей и расписания.
3. Пробные ответы каждого источника и сверка 10–20 карточек двух кабинетов по nmId, дате, времени среза и определению метрики.
4. Сверка общего итога, исторических остатков, воронки и рекламы с одинаковыми периодами WB.
5. Измерение ресурсов на полном ассортименте, повтор после перезапуска, проверка ежедневной доставки и резервирования.

Пункты реальной приёмки не выполнены. Архив является проверенной локально сборкой для последующего обновления, а не подтверждением установки или полного выполнения большого ТЗ в боевом окружении.
