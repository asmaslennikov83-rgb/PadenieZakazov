# Как пользоваться обновлённым ботом

Каждый день откройте «Обзор». В начале указано, полный ли результат. При неполных данных сначала проверьте «Качество данных»: известный подытог не равен итогу бизнеса.

Посмотрите общий результат двух кабинетов и компенсацию спада ростом. Затем — три первых проблемы по абсолютному отклонению и возможности для проверки. Нулевые заказы редкого товара отдельно помечены как редкий спрос; они остаются в полном файле.

«Ситуация сейчас» показывает последние наблюдавшиеся остатки и известный накопительный подытог сегодняшних заказов с временем обновления. Это незавершённый день. Сравнения «сегодня до текущего часа против полного вчера» нет. Текущий источник остатков не сообщает точное время обновления сервера: используется время наблюдения с указанной задержкой.

В «Проверить товар» используйте nmID или артикул продавца. При совпадениях выберите кабинет/карточку. Сравнение двух кабинетов появляется только после подтверждённого импорта соответствий с комплектностью. Наборы не сравниваются с единицами без нормализации.

«Рост и возможности» — основания для проверки и теста, а не команды увеличивать бюджет. Без подтверждённой экономики прибыльность не утверждается. Без сопоставимой доступности числовой объём сценария не рассчитывается. Сценарии одного товара не складываются автоматически.

## Кнопки и команды

- `/start`, `/menu` и прежние настройки сохранены.
- `/overview`, `/now`, `/drops`, `/growth`, `/stocks`, `/compare`, `/ads`, `/quality`, `/excel` — новые разделы.
- `/product 12345678` — карточка товара; можно указать артикул.
- `/actions` — сохранённые проверки.
- `/action ID DONE Имя` — ручная отметка выполнения; также OPEN, IN_PROGRESS, CANCELLED. Само бизнес-действие бот не выполняет.
- `/filters` — дополнительные фильтры. Примеры: `/filters min_base 1`, `/filters min_absolute 2`, `/filters repeat_days 2`, `/filters rare_mode separate`, `/filters growth_threshold 0.15`, `/filters stock_days 7`.
- `/filters urgent true` включает отдельные срочные сигналы риска запаса. По умолчанию они выключены. Риск по модели использует общий спрос карточки и требует проверки распределения спроса.

Порог прежнего режима по умолчанию строго более 15%. Новые фильтры не удаляют товары из полного пакета. Прежняя сортировка и старый формат доступны через «Прежний отчёт». Основной обзор ранжирует проблемы по абсолютному отклонению, без скрытого балла.

## Как переслать результат для анализа

Нажмите «Excel» и перешлите целиком полученный XLSX. Если бот прислал ZIP, перешлите весь ZIP: внутри обзор, полные CSV, manifest.json и словарь. Не отправляйте только обзор из ZIP — в нём нет всей истории.

Обзорные листы содержат результаты. Машинные таблицы — исходные доступные дневные показатели, снимки, определения, статусы и доказательства. Пустое числовое поле означает неизвестное значение, а не ноль. `STALE` — последний известный факт с возрастом. `NOT_APPLICABLE` — показатель неприменим, например день до подтверждённого создания карточки.

## Что ещё накапливается

Statistics запрашивается за целевые 90 дней при первом подключении. После этого обновляются последние изменения, с перекрытием 7 дней и учётом простоя. Полнота признаётся только после последней пустой страницы. При обрыве курсор сохраняется.

Дневная воронка WB ограничена последней неделей. Бот сохраняет доступные завершённые дни и постепенно накапливает историю. Агрегированное сравнение двух недель берётся отдельным методом и не превращается в вымышленную дневную историю.

История остатков запрашивается CSV за доступный период до 90 дней. Это срезы 23:59 МСК, а не непрерывное наличие весь день. Текущие снимки и цены сохраняются с начала работы новой версии; данные задним числом не создаются. По 90 дням годовая сезонность не определяется.

Ручные импорты маржи, соответствий, подтверждённой доступности и конкурентов выполняются администратором по шаблонам. Токены, сообщения покупателей и адреса в аналитический пакет не входят.
